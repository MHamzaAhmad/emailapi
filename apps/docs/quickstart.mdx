# Quickstart

This guide will get you sending emails in minutes using our TypeScript SDK.

<Steps>
  <Step title="Install the SDK">
    Install the package using your favorite package manager:

    <CodeGroup>
    ```bash npm
    npm install emailapi-sdk
    ```

    ```bash pnpm
    pnpm add emailapi-sdk
    ```

    ```bash yarn
    yarn add emailapi-sdk
    ```
    </CodeGroup>
  </Step>
  
  <Step title="Get your API Key">
    Sign up on the [dashboard](https://simpleemailapi.dev/dashboard), create a workspace, and grab your API key (starts with `em_`).
  </Step>
  
  <Step title="Send your first email">
    Create a client and send!

    ```typescript
    import { createClient } from 'emailapi-sdk';

    const client = createClient({
      apiKey: 'em_prod_123...'
    });

    await client.send({
      from: 'onboarding@yourdomain.com',
      to: ['you@example.com'],
      subject: 'Hello from SimpleEmailAPI',
      body: 'It works!'
    });
    ```
  </Step>
</Steps>
