# Quickstart

This guide will get you sending emails in minutes using our TypeScript SDK.

<Steps>

<Step>
### Install the SDK

Install the package using your favorite package manager:

```bash
npm install emailapi-sdk
```
</Step>

<Step>
### Get your API Key

Sign up on the [dashboard](https://dashboard.emailapi.dev), create a workspace, and grab your API key (starts with `em_`).
</Step>

<Step>
### Send your first email

Create a client and send!

```ts
import { createClient } from 'emailapi-sdk';

const client = createClient({
  apiKey: 'em_prod_123...'
});

await client.send({
  from: 'onboarding@resend.dev', // Use our test domain for now
  to: ['you@example.com'],
  subject: 'Hello from Email API',
  body: 'It works!'
});
```
</Step>

</Steps>
