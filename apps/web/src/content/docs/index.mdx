# Welcome to EmailAPI

EmailAPI is a developer-first platform for sending and receiving emails. We provide a simple REST API, a type-safe SDK, and high-performance gRPC endpoints.

## Features

- **Developer Experience**: Built for developers, by developers.
- **Type Safety**: End-to-type safety with our TypeScript SDK.
- **Performance**: High-throughput sending via gRPC.
- **Observability**: Real-time event streaming for every email status change.

## SDK Installation

```bash
npm install emailapi-sdk
```
